# yak-notification

一个保持 Java 8 二进制兼容的轻量通知核心。模块只抽取多个项目共同需要的稳定契约，
不绑定数据库、邮件服务商或 HTTP 客户端。

## 当前能力

- 站内信、邮件和 Webhook 三种渠道的统一请求模型；
- 使用 `${name}` 占位符的简单文本模板；
- 可替换的模板仓库、渠道发送器和发送记录仓库；
- 每个渠道独立记录成功或失败，单个渠道失败不会阻止其余渠道发送。

业务项目实现 `NotificationSender` 后，按渠道注册到 `DefaultNotificationService`。
持久化表、重试、异步队列和具体协议适配器应在出现共同需求后再增加，避免提前设计。
